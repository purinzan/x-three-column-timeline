# X 3-Column Timeline

Xのホームと投稿検索結果を、余白を詰めた独立3列で表示する非公式Chrome拡張。**v0.9.1 / MIT**

![実際のXホームを3列で表示](assets/timeline.jpg)

- **列固定の3列表示**：新しい投稿を短い列へ配置。追加読み込みはX本来の処理を利用。
- **下部メニュー**：ホーム・検索・通知・チャット・プロフィール。左端の正方形ボタンでX本来のメニューを開きます。
- **アイコンから有効／無効**：有効は3列、無効はX本来の表示。設定をブラウザ内に保存します。
- **自動スクロール**：アイコンからON/OFF・速度3段階。設定画面を閉じると開始し、手動操作終了の0.5秒後に滑らかに再開。入力・文字選択・メニュー中は待機、投稿詳細を開くとOFF。
- 縦長メディアは自動縮小。ホームと検索の「話題」「最新」の投稿に対応（ユーザー・画像・動画検索は対象外）。

## インストール

1. **Code → Download ZIP** から取得して展開。
2. `chrome://extensions` で **デベロッパーモード** をON。
3. **パッケージ化されていない拡張機能を読み込む** → `manifest.json` のあるフォルダを選択。
4. 同種のレイアウト変更拡張を無効にし、Xを再読み込み。

更新はファイルを差し替え、拡張管理画面とXを再読み込みしてください。ストア未公開のため自動更新はありません。

## 注意・プライバシー

X公式とは無関係の実験的な拡張です。Xの画面構造変更や環境によって表示が崩れることがあります。視覚上の順番と元の投稿順・キーボード順が異なる場合があります。未読バッジ転写は非対応。全画面幅・ズーム倍率・他拡張との互換性や長時間の安定性は未保証です。

独自サーバー・解析・外部送信はありません。`storage` 権限で表示・自動スクロールのON/OFFと速度をローカル保存。XページのDOM・投稿識別子は表示処理のためメモリ上で使用しますが、本文やアカウント情報は永続保存しません。X自身の通信は別です。

## 開発

ビルド・npm依存なし。Node.jsで `node test/autoscroll.test.js`、`node test/popup.test.js`、`node test/masonry.test.js`、`node test/layout.test.js` を実行できます。

`python3 -m http.server 8765 --bind 127.0.0.1` → `/test/fixture.html` でブラウザ検証。各シナリオ間は再読み込みしてください。`?demo` は撮影用の模擬画面です。一部の読書位置テストは画面サイズにより基準投稿を確保できない場合があります。

不具合は[Issues](https://github.com/purinzan/x-three-column-timeline/issues)へ。再現手順・Chromeバージョン・画面幅/ズーム倍率を添えてください。認証情報や実ページの生トレースは投稿しないでください。
