# X 3-Column Timeline

Xのホームタイムラインを、独立した3列（Masonry）で表示する非公式Chrome拡張機能です。

**個人開発の実験的な拡張です。X公式の製品ではなく、Xとの提携・承認はありません。** X側の画面構造の変更や環境によって表示が崩れる可能性があります。

## 機能

- ホームタイムラインを3列化。新しい投稿を短い列へ配置し、割り当て済みの列は固定。
- X本来の追加読み込み・投稿操作を利用。投稿要素を複製しません。
- 縦長画像・動画の表示高さを制限。
- 下部にメニュー・ホーム・検索・通知・チャット・プロフィールを表示。
- 拡張のポップアップでON/OFFを切り替え。

対象はホーム (`/home`) のみ。検索・プロフィールなどはX本来の表示に戻ります。

## インストール（Chrome / デスクトップ）

Chromeウェブストアには未公開です。GitHubから手動で読み込んでください。

1. このページの **Code → Download ZIP** でダウンロードし、展開します。
2. Chromeで `chrome://extensions` を開き、デベロッパーモードをONにします。
3. **パッケージ化されていない拡張機能を読み込む** を押し、`manifest.json` があるフォルダを選びます。
4. 同種のXレイアウト変更拡張を無効にし、Xのホームを再読み込みします。

更新時は新しいソースを同じフォルダへ配置し、拡張管理画面で再読み込みしてからXも再読み込みしてください。GitHubからの読み込みでは自動更新されません。

## 使い方

- 下部左端の正方形メニューで、X本来のナビゲーションを表示。Escapeまたは外側クリックで閉じます。
- 下部リンクはXの実際のナビゲーションから取得。取得できない項目は無効表示です。
- 縦長メディアは自動縮小します。切替ボタンはありません。
- 表示が崩れた場合は拡張のポップアップでOFFにし、必要に応じてXを再読み込みしてください。

## プライバシー・権限

- 拡張独自のサーバー、アクセス解析、外部送信処理はありません。
- 投稿本文やアカウント情報を永続保存しません。表示処理のため、XページのDOMや投稿識別子をメモリ上で使用します。
- `storage` 権限はON/OFF設定をブラウザ内 (`chrome.storage.local`) に保存するために使います。
- コンテンツスクリプトの対象は `x.com` と `twitter.com`。他サイトへのアクセスは要求しません。
- X自身が行う通信やデータ処理は、この拡張とは別です。

## 制約

- Xの非公開DOM構造に依存するため、将来の動作は保証できません。
- 視覚上の順番と元の投稿順・キーボード移動順は異なる場合があります。
- 通知の未読バッジは下部バーへ転写しません。
- スマートフォン、小さい画面、各種ズーム倍率、他拡張との全組み合わせは未検証です。
- スクロール・重なりの回帰テストはありますが、長時間の利用や全環境での無不具合・性能を保証するものではありません。

## 開発・検証

ビルド工程・npm依存関係はありません。

```sh
node --check content.js
node --check reading.js
node test/masonry.test.js
node test/layout.test.js
python3 -m http.server 8765 --bind 127.0.0.1
```

`http://127.0.0.1:8765/test/fixture.html` で模擬投稿の追加・再生成・メニュー・配置を確認できます。`?packing` では高さの異なる投稿の配置を確認できます。各シナリオの間はページを再読み込みしてください。模擬ページは実Xの通信・動画負荷を再現しません。一部の読書位置テストは画面サイズによって基準投稿を確保できない場合があります。
