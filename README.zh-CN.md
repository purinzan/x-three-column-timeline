# X 3-Column Timeline

非官方 Chrome 扩展，将 X 首页时间线显示为三个独立列，减少空白。**v0.8.5 / MIT**

![实际 X 首页的三列布局](assets/timeline.jpg)

- **固定列的三列布局**：新帖子放入当前最短的列，后续加载沿用 X 原有的机制。
- **底部导航**：首页、搜索、通知、聊天和个人资料。最左侧的方形按钮可打开 X 原有的菜单。
- **通过扩展图标启用或停用**：在三列布局与 X 原始布局之间切换，设置保存在本地浏览器中。
- 自动缩小纵向较长的媒体。仅支持首页时间线（`/home`）。

## 安装

1. 选择 **Code → Download ZIP**，下载并解压。
2. 打开 `chrome://extensions`，开启 **开发者模式**。
3. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 停用其他修改时间线布局的扩展，然后重新加载 X。

更新时请替换文件，在扩展管理页面重新加载扩展，再重新加载 X。本扩展尚未上架 Chrome 应用商店，不支持自动更新。

## 限制与隐私

本扩展为实验性项目，与 X 官方无关。X 页面结构或运行环境的变化可能导致布局异常。视觉排列顺序可能与原始帖子顺序及键盘导航顺序不同。不支持同步显示未读角标。不保证在所有窗口宽度、缩放比例或其他扩展组合下正常运行，也不保证长时间使用的稳定性。

无自建服务器、分析统计或对外数据发送。`storage` 权限仅用于在本地保存开关设置。X 页面的 DOM 和帖子标识符仅在内存中用于布局处理，不持久保存帖子正文或账号信息。X 自身的网络活动不在此范围内。

## 开发

无需构建，也无 npm 依赖。可使用 Node.js 运行 `node test/popup.test.js`、`node test/masonry.test.js` 和 `node test/layout.test.js`。

运行 `python3 -m http.server 8765 --bind 127.0.0.1`，在该服务器上打开 `/test/fixture.html` 进行浏览器验证。不同测试场景之间请重新加载页面。添加 `?demo` 可显示用于录制的模拟页面。某些阅读位置测试可能因窗口尺寸而无法找到参考帖子。

请通过 [Issues](https://github.com/purinzan/x-three-column-timeline/issues) 报告问题，并附上复现步骤、Chrome 版本、窗口宽度及缩放比例。请勿上传认证信息或真实页面的原始跟踪记录。
