# X 3-Column Timeline

X 홈 타임라인과 게시물 검색 결과를 독립된 3개 열로 표시해 빈 공간을 줄이는 비공식 Chrome 확장 프로그램입니다. **v0.9.1 / MIT**

![실제 X 홈의 3열 화면](assets/timeline.jpg)

- **열 위치를 유지하는 3열 배치**: 새 게시물을 현재 가장 짧은 열에 배치합니다. 추가 게시물은 X의 기본 로딩 방식으로 불러옵니다.
- **하단 메뉴**: 홈, 검색, 알림, 채팅, 프로필. 맨 왼쪽 정사각형 버튼으로 X의 기본 메뉴를 엽니다.
- **확장 아이콘에서 켜기／끄기**: 3열 화면과 X의 원래 화면을 전환합니다. 설정은 브라우저에 로컬로 저장됩니다.
- **자동 스크롤**: 아이콘에서 켜기／끄기와 3단계 속도를 선택합니다. 설정을 닫으면 시작하고, 수동 조작 종료 0.5초 후 부드럽게 재개합니다. 입력・텍스트 선택・메뉴 표시 중에는 대기하며, 게시물 상세를 열면 꺼집니다.
- 세로로 긴 미디어를 자동 축소합니다. 홈 및 인기／최신 게시물 검색을 지원하며 사용자・이미지・동영상 검색은 변경하지 않습니다.

확장 아이콘에서 설정할 수 있습니다. 이미지와 영상은 이전 버전에서 촬영했으며 현재는 자동 스크롤 및 속도 선택도 있습니다.

## 설치

1. **Code → Download ZIP**을 선택해 다운로드하고 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 클릭하고 `manifest.json`이 있는 폴더를 선택합니다.
4. 타임라인 레이아웃을 변경하는 다른 확장 프로그램을 끄고 X를 새로고침합니다.

업데이트하려면 파일을 교체한 뒤 확장 프로그램 관리 화면에서 확장을 새로고침하고, X도 새로고침하세요. Chrome 웹 스토어에 출시되지 않아 자동 업데이트는 지원하지 않습니다.

## 제한 사항 및 개인정보

X 공식 서비스와 무관한 실험적 확장 프로그램입니다. X의 페이지 구조나 실행 환경이 바뀌면 화면이 깨질 수 있습니다. 시각적 배치 순서는 원래 게시물 순서 및 키보드 탐색 순서와 다를 수 있습니다. 읽지 않음 배지의 동기화 표시는 지원하지 않습니다. 모든 창 너비, 확대／축소 비율, 다른 확장 프로그램과의 호환성 및 장시간 사용 시 안정성은 보장하지 않습니다.

자체 서버, 분석 도구, 외부 데이터 전송은 없습니다. `storage` 권한은 레이아웃 및 자동 스크롤 켜기／끄기와 속도를 로컬에 저장하는 데 사용합니다. X 페이지의 DOM과 게시물 식별자는 레이아웃 처리를 위해 메모리에서 사용하지만, 게시물 본문이나 계정 정보는 영구 저장하지 않습니다. X 자체의 네트워크 통신은 별개입니다.

## 개발

빌드 과정과 npm 의존성이 없습니다. Node.js로 `node test/autoscroll.test.js`, `node test/popup.test.js`, `node test/masonry.test.js`, `node test/layout.test.js`를 실행할 수 있습니다.

`python3 -m http.server 8765 --bind 127.0.0.1`을 실행한 뒤 해당 서버의 `/test/fixture.html`을 열어 브라우저에서 확인합니다. 시나리오를 바꿀 때는 페이지를 새로고침하세요. `?demo`를 추가하면 촬영용 모의 화면이 표시됩니다. 일부 읽기 위치 테스트는 창 크기에 따라 기준 게시물을 찾지 못할 수 있습니다.

버그는 [Issues](https://github.com/purinzan/x-three-column-timeline/issues)에 재현 방법, Chrome 버전, 창 너비와 확대／축소 비율을 첨부해 알려 주세요. 인증 정보나 실제 페이지에서 수집한 원본 추적 기록은 올리지 마세요.
